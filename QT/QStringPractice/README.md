# 📌 基础核心：QString 字符串类实战大全

**📂 项目路径**：`QT/QStringPractice`

**🎯 项目背景：**
`QString` 是 Qt 框架中最基础、最核心的数据类型之一。它底层采用了 UTF-16 编码，完美支持跨平台和多语言（包括中文）。本项目通过系统化的测试 Demo，全面覆盖了字符串的构造、增删改查、编码转换、格式化输出及遍历操作。

## 🌍 一、典型使用场景

1. **UI 交互与数据展示**：读取用户输入（如 `QLineEdit`），并将其格式化后显示在界面上（如 `QLabel`）。
2. **文件与网络处理**：解析文件路径、提取文件扩展名、处理网络请求中的 JSON 字符串或 URL 参数。
3. **数据格式化**：将后台传来的浮点数精确保留小数位，或进行十六进制等进制转换。

## 🛠️ 二、核心知识点与 API 拆解

### 1. 构造与拼接

- **构造**：支持空构造、从 C 风格字符串构造、从 `QByteArray` 构造、或者用字符和数量构造（如 `QString(5, 'A')` 得到 "AAAAA"）。
- **拼接三剑客**：
  - `+` 操作符：直观简单，但**大量拼接时性能较差**（每次都会产生新对象）。
  - `.append()`：链式调用，在尾部追加。
  - **`.arg()` 占位符（🔥 强烈推荐）**：`QString("%1,%2").arg(a).arg(b)`。性能最高，且极大提升代码可读性。

### 2. 查找与截取

- **查找**：`indexOf()` 找首次出现位置，`lastIndexOf()` 找最后一次出现位置。**注意：索引从 0 开始计算。**
- **截取**：
  - `.left(n)`：截取左边 n 个字符。
  - `.right(n)`：截取右边 n 个字符。
  - `.mid(pos, n)`：从 pos 开始，截取 n 个字符。
  - `.section(分隔符, 起始段, 结束段)`：按规则切分（如截取 URL 中的某一段）。

### 3. 切割与合并

- **切割**：`.split(",")` 将字符串按逗号拆分成一个 `QStringList`（字符串列表）。
- **合并**：`.join(";")` 将 `QStringList` 中的元素按分号拼接回一个长字符串。

### 4. 空白处理（表单校验神器）

- `.trimmed()`：去掉字符串首尾的空白字符（空格、换行、Tab）。
- `.simplified()`：去掉首尾空白，并将中间连续的多个空白字符压缩为一个空格。**（用户输入表单时必用）**

### 5. 数字与字符串的互转

- **数字转字符串**：`QString::number(123)` 转整数，`QString::number(3.14159, 'f', 2)` 保留两位小数。
- **字符串转数字**：`toInt(&ok)`、`toDouble(&ok)`。**核心防坑**：必须传入 `bool` 变量的地址（`&ok`），以判断转换是否成功，防止用户输入字母导致崩溃。

### 6. 格式化输出 (`arg` 高级用法)

- `QString("%1").arg(123, 5, 10, QChar('0'))` 表示将 123 转为宽度为 5、10 进制、用 `'0'` 填充的字符串，结果为 `"00123"`。

## ⚠️ 三、实战避坑与性能优化

### 🚨 坑点 1：大量字符串拼接的性能灾难

- **现象**：在 `for` 循环中使用 `+` 拼接一万次字符串，程序会卡顿甚至卡死。
- **原因**：`+` 每次都会重新分配内存并拷贝数据。
- **✅ 解决方案**：在循环开始前使用 `.reserve(10000)` 预留内存，或者使用 `QStringList` 收集每一段，最后统一 `join("")`。

### 🚨 坑点 2：隐式共享 (Copy-on-Write)

- **现象**：`QString str2 = str1;` 不会立即复制数据，而是共享同一块内存。只有当你尝试修改 `str2` 时，Qt 才会真正复制一份数据（写时复制）。
- **优势**：传参和赋值极快，节省内存。
- **坑点**：在多线程环境下修改共享数据会导致数据竞争。需要使用 `QString::detach()` 强制分离。

### 🚨 坑点 3：中文乱码（编码问题）

- **现象**：读取外部文件或网络数据时，中文字符变成乱码。
- **✅ 解决方案**：明确使用 `QString::fromUtf8(byteArray)` 或 `QString::fromLocal8Bit(byteArray)` 进行解码，强制指定 UTF-8 字符集。

## 💻 四、核心代码实现

### 1. 字符串拼接与格式化

```cpp
QString str1 = "Hello";
QString str2 = "World";

// 推荐做法：arg 占位符替换
QString result = QString("%1, %2").arg(str1).arg(str2);
qDebug() << result; // "Hello, World"

// 高级格式化：补零 (输出 "00123")
QString s5 = QString("%1").arg(123, 5, 10, QChar('0'));
qDebug() << s5;
```

### 2. 安全转换 (`bool` 防坑)

```cpp
bool ok;
int num = QString("abc").toInt(&ok); // 转换失败
if (!ok) {
    qDebug() << "非法数字输入！"; // 程序走这里
}
```

### 3. 空白字符清理

```cpp
QString s3 = "  Hello    World  ";
s3 = s3.trimmed();    // "Hello    World"
s3 = s3.simplified(); // "Hello World" (中间的多余空格被压成一个)
```

### 4. 字符串遍历（三种方式）

```cpp
QString list1 = "Hello";

// 方式一：索引遍历
for(int i = 0; i < list1.length(); i++) {
    qDebug() << list1[i];
}

// 方式二：foreach 宏（Qt 旧写法，不推荐）
foreach(QChar ch, list1) {
    qDebug() << ch;
}

// 方式三：C++11 范围 for 循环（✅ 现代标准写法）
for(QChar ch : list1) {
    qDebug() << ch;
}
```
